# static-prototype-dev 使用说明

用于新建或迭代以 HTML、原生 JavaScript、CSS 为主的多页面静态交互原型，支持角色页面、业务模块、模拟数据和跨页状态。仅做产品方案、正式后端开发或纯视觉图片时不使用。

- [技能说明](../skills/static-prototype-dev/SKILL.md)
- [显示信息](../skills/static-prototype-dev/agents/openai.yaml)

## 迁入与安装状态

从本机已安装的 `~/.codex/skills/static-prototype-dev/` 原样复制整个目录，包含 `SKILL.md` 和 `agents/openai.yaml`。源目录没有脚本、外部文件依赖或第三方许可证文件；技能内容没有写死的本机路径。生成原型时按需引入的 CDN 或图表库，需要在目标项目中说明依赖。

原安装目录保留，本次没有安装、覆盖或建立链接。当前会话已有该技能；仓库副本与已安装副本相互独立，修改仓库不会自动更新原安装。

## 调用示例

新建原型：

```text
使用 $static-prototype-dev，在 <目标目录> 创建课程管理静态交互原型。
角色：教师。
页面：课程列表、课程详情与编辑。
核心流程：从列表进入详情，编辑课程名称并保存，返回列表后显示更新结果，刷新后保留修改。
使用 HTML、原生 JavaScript、CSS，无构建步骤；提供模拟数据、运行说明并验证核心流程。
```

迭代已有项目：

```text
使用 $static-prototype-dev，修改 <项目目录> 的课程列表与详情页。
增加课程状态筛选，在详情页修改状态后同步列表，刷新后保留结果。
沿用现有目录、视觉与存储键，检查受影响页面，并更新运行说明。
```
